"The Cinema" LUT

I've been down the rabbit hole of film looks, substractive saturation, cinematic color shifts, filmic contrast, color grading with resolve and all that stuff. I'm no expert and in the end it all comes down to taste... anyway, here's my LUT (+ variants) I refined in the process (so far). Works great with grain and some character lens or mist filters.

Some image examples of "The Cinema": https://www.reddit.com/r/Lumix/comments/1pky8ea/free_photo_lut_the_cinema/

All .cube files here are 33 point LUTs to be used as Lumix RealTime LUTs. Have fun!
